# AutomotiveXperts Mobile

Erste lauffähige Expo/React-Native-Grundversion der AutomotiveXperts App.

## Enthalten
- Expo / React Native Grundprojekt
- Startbildschirm
- Bereiche für Neues Gutachten, Fahrzeuge und Gutachten
- iOS- und Android-Konfiguration

## Start
1. Abhängigkeiten installieren: `npm install`
2. Expo starten: `npx expo start`
3. QR-Code mit Expo Go öffnen.
